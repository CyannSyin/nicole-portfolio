# FinCost portfolio assets

The case study already uses the official overview, framework, and selected deployment examples from the FinCost repository. Add the following final product captures here.

## Toolkit demo

- Filename: `fincost-demo.mp4`
- Format: MP4, H.264, muted is fine
- Length: 30–45 seconds
- Ratio: 16:9, ideally 1920×1080 or larger
- Do not expose API keys, environment variables, private trading records, or personal financial information.
- Suggested sequence:
  1. Open `config.json` and identify records, static config, prices, and diagnosis model.
  2. Run FinCost against one experiment.
  3. Open the generated summary bill.
  4. Show the cost breakdown and gross-profit / cost / net-profit chart.
  5. Open the diagnosis report and highlight the top configuration recommendation.

## Report screenshot

### `fincost-report.png`

- 1920×1080 or larger.
- Prefer the rendered HTML report rather than a terminal screenshot.
- Keep these elements visible: total system cost, gross result, net result, cost breakdown, latency or opportunity cost, and the first recommendation.
- Use an included example or sanitized research record only.
